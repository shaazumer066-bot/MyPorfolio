# Shaaz Umer — Personal Portfolio 

Hey there! I'm **Shaaz Umer**, a student and self-taught developer who loves building cool stuff with code and learning things by actually messing up and fixing them.

This repo holds the source code for my personal portfolio website.

## About

I decided to build this portfolio to have a single spot where I can showcase:

- My projects — the stuff that actually works!
- Things I'm currently learning
- Random tech interests
- My overall journey as a developer
- Ways to get in touch with me

I really wanted the site to feel uniquely mine rather than just grabbing a pre-made template, so I ended up building it from scratch using plain old **HTML, CSS, and JavaScript**.

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Featured Projects

Here are a few projects featured on the site:

### DropFlow

A quick little Windows desktop app I built that cleans up messy folders by automatically sorting files into their proper categories.

**Tech:** Electron, JavaScript, HTML, CSS

### PulseTab

A custom browser new-tab dashboard built to replace the plain default start page with something way more useful and aesthetic.

### shaazOS

A lightweight, web-based simulated operating system running entirely in your browser.

**Tech:** HTML, CSS, JavaScript

Since I'm still learning every day, this site doubles as a personal timeline so I can look back and see how my skills evolve over time.

It's definitely a work in progress and far from perfect, but I'm constantly updating it as I pick up new tools and concepts.
